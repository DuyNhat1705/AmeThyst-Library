### 1. Phan Lê Anh Minh
- **Personal Contribution:** I used the Spec Kit workflow to specify, plan, decompose, implement, and review several parts of the system, including authentication and profile features, interactive UI effects, Admin User Management, notification unification, and the authentication registration test-suite reduction. I reviewed AI-generated changes against the existing architecture, narrowed unnecessary scope, corrected outdated assumptions, refined the UI and security behavior, and verified the final work through Git diffs and test evidence.
- **Personal Learning:** I learned that AI-generated code and documentation must be treated as a draft rather than accepted as the final answer. I became better at translating requirements into traceable specifications, assigning tests to the correct service, controller, or integration layer, and distinguishing a faulty test from a legitimate failure that exposes a real defect. I also learned to define security, accessibility, data-consistency, and scope constraints before implementation, and to rely on actual execution results rather than unchecked tasks or confident AI claims.
