## I. What went well
- We have Use-Case Diagram providing us the general view of all available use cases in the system.
- We have a Use-Case Specification for each use case to describe how it actually works.
- In terms of implementation of our product, we have:
  - 3 more functional groups completed: Study Group, AI Recommendation, Borrowing & Reserving
  - Return-Book Confirmation, Loan Record, Book Management in Librarian Administraion
## II. Problems
- Heavy workload during mid-term exam week, requiring us to rush and complete deadlines in a short time frame.
- Initial confusion regarding the operational concept of the room reservation mechanism.
- Taking significant time to get familiar with using Socket.io for real-time messaging features.
- The number of use-case specifications is large, requiring us to reorganize the headings and layouts for better readability.
- Mermaid’s lack of proper notation support for Use-Case Diagrams, making it difficult to fully convey diagram meanings when migrating from Draw.io.
## III. What can be done differently in next sprint to improve
- Plan around exam weeks in advance — schedule lighter tasks before mid-terms so we're not scrambling to catch up.
- Before starting a new feature, take 30 minutes as a team to make sure everyone understands how it's supposed to work — this saves a lot of confusion later.
- Give ourselves a bit of ramp-up time to learn new tools (like Socket.io) before diving into the actual implementation, instead of learning as we go.
- Agree on a consistent format for use-case specs early on, and pick a diagramming tool that actually supports Use-Case Diagrams properly, so we don't run into notation issues down the line.
## IV. What lessons we could learn
- Good documentation (diagrams + specs) really helps the team stay on the same page.
- Learning a new tech mid-sprint slows things down. It's better to learn it first, then build.
- We tend to underestimate how much exam weeks eat into our available time — next time, we should plan more conservatively around them.
